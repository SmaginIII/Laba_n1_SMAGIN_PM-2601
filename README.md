### 1. Постановка задачи

> Программа получает на вход два параметра a и b. <img width="108" height="39" alt="image" src="https://github.com/user-attachments/assets/06e6ef19-1e86-475c-b2a2-97b39abe3d26" />
> Решает его для х.

Данную задачу можно разделить на две подзадачи:
1) Получение данных с клавиатуры
2) Анализ параметров и вывод правильного ответа

### 2. Входные и выходные данные

#### Данные на вход

На вход программа должна получать 2 числа, при этом в условии не сказано, к какому типу данных принадлежат получаемые числа, поэтому будем считать их вещественными типа(double).

#### Данные на выход

Программа должна вывести множество значений х, при котором неравенство выполняется (реализуется через System.out.ptintf).

### 3. Выбор структуры данных

Программа получает 2 вещественных числа. Для их хранения
можно выделить 2 переменных (`a` и `b`) типа `double`.

|                | название переменной | Тип (в Java) | 
|----------------|---------------------|--------------|
| a (параметр 1) | `a`                 | `double`     |
| b (параметр 2) | `b`                 | `double`     | 

### 4. Алгоритм

#### Алгоритм выполнения программы:

1. **Ввод данных:**  
   Программа считывает два вещественных числа, обозначенные как `a` и `b`.
   
2. **Анализ данных:**
   Программа определяет левый/правый корень знаменателя, далее:
   1)Если а = 0, то решений нет (т.к 0=0, противоречие)
   2)Если a>0, то числитель должен быть отрицательным, выводится множество x, при которых парабола x(x+b) принимает отрицательные значения.
   3)Если a<0, то числитель должен быть положительным, выводится множество x, при которых парабола x(x+b) принимает положительные значения.

3. **Вывод результата:**
   Программа выводит результат прошлого пункта
